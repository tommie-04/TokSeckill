# 学习与改进导航

围绕业务场景，按“问题 → 方案 → 实现 → 验证 → 面试表达”学习。

| 主题 | 需要回答的问题 | 验证方向 |
| --- | --- | --- |
| 缓存 | 穿透与击穿的区别？逻辑过期适用于什么数据？ | 缓存命中、过期、空值、数据库故障 |
| Caffeine | 为什么 Redis 前再加本地缓存？多实例怎么更新？ | 同负载对比 MySQL / Redis / Caffeine 模式 |
| 秒杀 | 资格校验为什么放 Lua？预扣成功后消息失败怎么办？ | 库存边界、重复请求、消息发送失败 |
| Kafka | 何时提交 offset？消费失败和重复消息怎么处理？ | 重试、幂等、积压、恢复 |
| 锁 | 为什么本地锁无法协调多实例？如何避免误删？ | 锁超时、持有者、并发释放 |
| 事务 | 扣库存成功、创建订单失败怎么办？ | 强制插入失败并检查回滚 |
| 限流 | 固定窗口和滑动窗口的差异？按什么维度限流？ | 窗口边界、用户与 IP 隔离 |
